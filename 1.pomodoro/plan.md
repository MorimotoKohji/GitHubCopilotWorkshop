# ポモドーロタイマー 段階的実装計画

## Phase 1 — 完全なポモドーロサイクル
**目標：ポモドーロ技法として最低限成立する状態**

| # | 実装内容 | 対象ファイル |
|---|---|---|
| 1-1 | 短い休憩タイマー（5分）の追加 | `timer.js` |
| 1-2 | 長い休憩タイマー（15分）の追加 | `timer.js` |
| 1-3 | 作業→短い休憩→作業→…の自動切り替え | `timer.js` |
| 1-4 | 4セッション完了後に長い休憩へ切り替え | `timer.js` |
| 1-5 | 現在のセッション数表示（例：2/4） | `index.html` / `timer.js` |
| 1-6 | フェーズに応じたリングの色変更（休憩時は緑系） | `style.css` / `timer.js` |

完了条件：25分→5分→25分→5分→25分→5分→25分→15分 のサイクルが自動で回る

## Phase 2 — UX 通知・フィードバック
**目標：画面を離れていても使えるレベルの UX**

| # | 実装内容 | 対象ファイル |
|---|---|---|

## Phase 3 — カスタマイズ設定
**目標：ユーザーが自分の好みに合わせて時間を変更できる**

| # | 実装内容 | 対象ファイル |
|---|---|---|

| 3-3 | 設定変更時にタイマーをリセット | `timer.js` |

完了条件：ページをリロードしても設定が維持される

## Phase 4 — 履歴・統計
**目標：継続的な利用を促すデータ可視化**

| # | 実装内容 | 対象ファイル |
|---|---|---|
| 4-1 | `progress.json` を日別配列に拡張（バックエンド） | `progress.py` / `app.py` |
| 4-2 | 過去7日分の進捗を返す `GET /api/history` API | `app.py` |
| 4-3 | 日別集中時間の棒グラフ表示（Canvas / SVG） | `index.html` / `timer.js` / `style.css` |
| 4-4 | バックエンドのテストを更新（履歴 API 対応） | `test_progress.py` / `test_routes.py` |

完了条件：過去1週間の集中時間がグラフで確認できる

---

## フェーズ間の依存関係

```
Phase 1（サイクル完成）
    └──▶ Phase 2（通知）   ← Phase 1 のセッション状態に依存
    └──▶ Phase 3（設定）   ← Phase 1 のタイマー定数に依存
              └──▶ Phase 4（履歴）← Phase 1 のデータモデルに依存
```

Phase 2 と Phase 3 は並行して進めることができます。  
Phase 4 はバックエンドのデータモデル変更を伴うため、Phase 1〜3 が安定してから着手するのが安全です。
