# ポモドーロタイマー 機能一覧

## ✅ 実装済み

### コア機能
- 25分カウントダウンタイマー（作業）
- 短い休憩タイマー（5分）
- 長い休憩タイマー（15分）
- 自動切り替え（作業 → 短い休憩 → … → 長い休憩）
- 現在のセッション数表示（例：2/4）
- 開始 / 一時停止 / 再開
- リセット（25:00 に戻す）

### UI
- SVG 円形プログレスリング（残り時間に連動）
- フェーズラベル表示（「作業中」「短い休憩」「長い休憩」）

### 進捗管理
- 作業セッション完了の記録（サーバー保存）
- 今日の完了数・集中時間の表示
- 日付をまたいだ自動リセット
